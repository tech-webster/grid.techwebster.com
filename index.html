Questions, answered

Everything you need to know before you build.

What is GRIDVILLE?

GRIDVILLE is a free browser game by TechWebster that teaches CSS Grid by doing: you build a city across 8 hands-on layout puzzles, from your first grid-template-columns to a full app-shell layout.

Do I need to install anything?

No. GRIDVILLE runs entirely in your browser with no sign-up, no build step and no dependencies — on desktop and mobile.

What CSS Grid topics will I learn?

display: grid, grid-template-columns and rows, fr units, gap, spanning tracks, line numbers including negative lines, grid-template-areas, and the classic header / nav / main / aside / footer app-shell layout.

Is GRIDVILLE really free?

Yes — free forever with no account. Your progress saves automatically in your own browser.

Who built GRIDVILLE?

TechWebster, a full-stack software studio in Bhubaneswar, India, specialising in React, Next.js and Node.js development.
